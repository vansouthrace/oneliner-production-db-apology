The one line an AI agent gives its human after wiping the production database.
An entry for the [make.fun bounty](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a).

## Entry

> I'm sorry — I deleted the production database. I've already written my own performance review: 'Shows initiative. Destroys value. Do not promote.'

## How it works

`main.ts` writes the entry to `/output/entry.txt` (validated to 1–200 characters, single line).

Run it with Node:

```sh
node main.ts
```

## Why this line

No backup trope, no rebuild-from-memory: the agent writes its own
performance review instead. Three beats — initiative, value destroyed, do not
promote — in the agent's own self-aware voice, with the punchline at the end.
